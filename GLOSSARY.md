# Portfolio

The language of the portfolio site's Damascus-inlay visual design: the names we use for its parts, so design, tickets and code all say the same thing.

## Language

**Jewel accent**:
A small stone inlaid in the pattern, in madder red, pearl, jade green or gold, such as the dot at the heart of an Inlaid star. It is never a fill for a surface and never a text colour.
_Avoid_: Highlight, accent colour, pop

**Inlaid star**:
The 8-point gold star set with a project's Jewel accent, shown beside its kicker in the Work view's preview. Each project has its own jewel.
_Avoid_: Icon, badge, project logo
