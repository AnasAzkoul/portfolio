# Portfolio

The language of the portfolio site's Damascus-inlay visual design: the names we use for its parts, so design, tickets and code all say the same thing.

## Language

**Jewel accent**:
A small stone inlaid in the pattern, in madder red, pearl, jade green or gold, such as the dot at the heart of a Cartouche's star. It is never a fill for a surface and never a text colour.
_Avoid_: Highlight, accent colour, pop

**Cartouche**:
The framed tile that stands for one project on the Work view: its number, an inlaid star set with a Jewel accent, its name and its stack.
_Avoid_: Card, project tile
