# Portfolio

The language of the portfolio site's Damascus-inlay visual design: the names we use for its parts, so design, tickets and code all say the same thing.

## Language

**Jewel accent**:
A small, saturated inlay mark (a madder red or jade green stone) set into the gold-and-pearl pattern. It is never a fill for a surface and never a text colour.
_Avoid_: Highlight, accent colour, pop
